# Školní projekty (VUT FIT)

Repozitář pro moje školní projekty během studia na **VUT FIT**. Struktura je dělená podle semestrů a předmětů.

> Pozn.: Nahrané zdrojáky a řešení slouží pro vlastní archivaci a učení. Respektuj pravidla akademické integrity (neodevzdávej cizí řešení jako své).

## Struktura

- `1. semestr/`, `2. semestr/`, … – rozdělení podle semestrů
- V každém semestru složky podle zkratek předmětů (např. `IZP`, `IOS`, …)
- U každého předmětu je `README.md` s přehledem projektů a poznámek

## Doporučené konvence

- Projekty pojmenovávej konzistentně: `projekt-01/`, `projekt-02/`, `ukol-01/`, `seminarka/`, `zkouska/`…
- Přidej `.gitignore` podle jazyka (C/C++, Python, LaTeX, …)
- U větších projektů dej do složky projektu vlastní `README.md` s:
  - zadáním (odkaz / stručný popis),
  - způsobem spuštění,
  - závislostmi,
  - výsledky (např. screenshoty, grafy).
