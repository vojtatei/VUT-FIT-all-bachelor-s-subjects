# 🎓 Školní projekty – FIT VUT

Tento repozitář obsahuje moje školní projekty a materiály ze studia na **Fakultě informačních technologií VUT v Brně (FIT VUT)**.

Repo slouží jako osobní archiv projektů, poznámek a ukázek řešení z jednotlivých předmětů během bakalářského studia.

## ⚠️ Akademická integrita

Tento repozitář je veřejný pouze pro účely prezentace práce a studia.

Pokud studuješ na FIT VUT nebo jiné škole:

❌ Nekopíruj řešení přímo do svých odevzdání.  
❌ Nepoužívej kód bez pochopení.

Používej obsah pouze jako:
- studijní inspiraci
- referenci k architektuře projektu
- ukázku stylu řešení
