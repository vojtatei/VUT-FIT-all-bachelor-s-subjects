# T9: Zdravotnictví, wellness, zdravotnické služby

Zvolte si oblast z okruhu péče o zdraví:

- lékařská zařízení  
- farmaceutická výroba  
- epidemiologie  
- výzkum  
- služby  

Vytvořte model typu:

- SHO (systém hromadné obsluhy),  
- CA (celulární automat),  
- nebo obecný diskrétní / spojitý model.  

Zkoumejte chování systému.
